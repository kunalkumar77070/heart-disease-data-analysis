# Heart Disease Data Analysis

A Python-based exploratory data analysis (EDA) project using the Cleveland Heart Disease dataset from the UCI Machine Learning Repository.

## Project Objective

The goal of this project is to explore heart disease data, understand important features, identify patterns, and visualize relationships between different health-related variables.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Analysis Performed

- Dataset overview
- Data types and structure
- Missing value analysis
- Duplicate record detection
- Unique value analysis
- Statistical summary
- Mean, median, and standard deviation
- Target class distribution
- Age distribution
- Cholesterol analysis
- Resting blood pressure analysis
- Chest pain type analysis
- Correlation analysis

## Dataset

The project uses the Cleveland Heart Disease dataset from the UCI Machine Learning Repository.

The original target variable is converted into a binary target:

- `0` = No heart disease
- `1` = Heart disease present

## Project Files

- `heart_disease_analysis.ipynb` — Complete Jupyter Notebook
- `analysis.py` — Python analysis script
- `requirements.txt` — Required Python libraries
